# CrossApp

Наскрізний проєкт з крос-платформного програмування.

## Предметна область

**Бібліотека**

Основні сутності:

- `Book` — книга;
- `BookCopy` — конкретний примірник книги;
- `Reader` — читач;
- `Loan` — видача примірника книги читачеві.

## Призначення

Проєкт призначений для обліку видачі та повернення примірників книг читачами.
